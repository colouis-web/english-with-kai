Option C — Dashboard

Façon Duolingo : carte objectif + bande des 7 jours avec la série, puis des sections repliables (My memory, This week, My level, My rewards, Certificates) dont l'état ouvert / fermé est mémorisé.

À essayer

  • Ouvrir 2 sections, recharger la page : elles restent ouvertes.
  • Pastille orange sur « Certificates » à J-7.
  • Start → la bande des 7 jours passe au vert pour lundi.

Certificates

  • Section repliable avec les badges + bandeau Renew en haut à J-7 ; page complète depuis la section ou la tuile du menu.

Hauteur « Today »

≈ 1 170 px tout replié (mesuré) ; ≈ 1 950 px avec 3 sections ouvertes ; ≈ 3 000 px si tout est ouvert.
