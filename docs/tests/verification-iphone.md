# Vérification sur iPhone — 5 minutes, à chaque nouvelle version

À faire par **le fils**, sur **son iPhone**, avant que la nouvelle version soit déclarée « bonne ».
Un parent peut rester à côté pour noter. Tu n'as rien à réparer : tu regardes, tu coches, tu notes.

- Date : ______ / ______ / ________
- Modèle de l'iPhone : ______________________ (Réglages > Général > Informations)
- Numéro de version : ______________ (ouvre dans Safari l'adresse du site suivie de `/version.json` et recopie la ligne « version »,
  par exemple `v2026.11.05.3`. Le petit « v0.2 » en bas de l'accueil n'est pas le bon numéro : ne le recopie pas.)
- Ton prénom dans l'app : ______________________

**Règle d'or :** si quelque chose est bizarre (image coupée, texte trop petit, bouton qui ne répond pas),
**ne cherche pas pourquoi**. Fais une capture d'écran (bouton de côté + bouton volume haut), coche la case « ✗ »
et écris l'écran dans « Remarques » à la fin.

---

## A. Ouvrir l'application (Safari)

- [ ] **1. Ouvrir le site.** Dans Safari, ouvre l'adresse du site (le lien dans tes favoris ou celui que papa t'a envoyé).
      La page avec Kai s'affiche en moins de 5 secondes, avec « Learning English with Kai » en haut.
- [ ] **2. L'accueil est bien cadré.** Tu vois Kai entier (sa tête n'est pas coupée) et le gros bouton **Start** sans avoir
      à faire défiler la page.
- [ ] **3. Ajouter à l'écran d'accueil.** Touche le bouton Partager (le carré avec une flèche vers le haut), choisis
      « Sur l'écran d'accueil », puis « Ajouter ». L'icône de Kai apparaît parmi tes applications.
- [ ] **4. Ouvrir depuis l'icône.** Touche l'icône de Kai : l'application s'ouvre en plein écran, sans la barre d'adresse de Safari.

## B. Apprendre

- [ ] **5. Mots du jour.** Touche **Start** (ou « Bonus round »), puis réponds à 3 questions. Les boutons réagissent du premier coup
      (pas besoin d'appuyer deux fois). Une bonne réponse devient verte ; une erreur montre la bonne réponse.
- [ ] **6. Le son.** Mets le volume au milieu et vérifie que l'interrupteur du côté de l'iPhone n'est pas sur « silencieux »
      (pas de point orange). Touche un petit haut-parleur : tu entends Kai (ou une voix) dire le mot en anglais.
- [ ] **7. Un quiz jusqu'au bout.** Menu > Test yourself > Quiz : choisis un thème, fais un quiz de 5 mots jusqu'à l'écran de fin.
      Kai apparaît à la fin avec ton score, sans être coupé.

## C. Lire et regarder

- [ ] **8. Le texte est lisible.** Dans les bulles de Kai et dans les questions, tu lis **sans zoomer** et sans plisser les yeux.
      Aucun mot n'est coupé sur le bord de l'écran.
- [ ] **9. Les images sont bien cadrées.** Regarde ces 5 écrans : **l'accueil**, **My daily work** (les petits visages de Kai
      pour l'humeur), **Let's talk English** (la grande image), **Congrats!** (Kai pouce levé, après un tour de mots du jour)
      et **le menu**. À chaque fois, Kai est entier : visage, mains et pieds ne sont pas coupés en haut, en bas ni sur les côtés.
- [ ] **10. Rien ne bouge sur le côté.** Sur 3 écrans de ton choix, glisse le doigt vers la gauche puis vers la droite :
      la page ne se déplace pas sur le côté et rien ne dépasse de l'écran.

## D. Garder son travail

- [ ] **11. Quitter et revenir.** Quitte l'application (glisse depuis le bas de l'écran), puis rouvre-la depuis l'icône :
      tu retrouves ton écran « My daily work », sans avoir à retaper ton prénom.
- [ ] **12. Sauvegarde.** Menu > Me > **Save my progress** : le message « Saved: kai-english-… » apparaît et le fichier
      se trouve dans l'application **Fichiers** (dossier Téléchargements ou iCloud Drive).
- [ ] **13. La progression est toujours là.** Ferme complètement l'application (glisse-la vers le haut dans le sélecteur d'applications),
      rouvre-la : tes étoiles, ton niveau et tes mots du jour sont toujours là.

## E. Pour les parents

- [ ] **14. Code parent.** Si un code parent est réglé : changer le niveau de l'élève (Me > niveau) demande le code,
      et un mauvais code est refusé avec le message « Wrong code ».
